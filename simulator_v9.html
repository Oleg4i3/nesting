Редактор деталей

Намалюйте деталі (клік по вузлах сітки — вершини, клік по першій — замкнути; клік по ребру, потім по точці — крива Без'є; перетягування, поворот, дзеркало, клонування й скасування — кнопками). Потім створіть із них задачу або додайте до поточної; ширину рулона й повороти задаються над результатами.

Формати вхідних файлів

Підтримуються три формати. (1) Власний nest-scene-v1: пазли й тести з цього репозиторія. (2) Набори ESICUP / Sparrow (items, strip_height): деталі масштабуються так, щоб висота смуги дорівнювала 300 px, повторення за demand розгортаються. (3) JSON редактора розкрою (polygons з vertices і bezierControls).

{
 "format": "nest-scene-v1",
 "name": "my_task", "title": "Моя задача",
 "width": 300,                       // ширина рулона, px
 "rotations": [0, 90, 180, 270],     // дозволені кути, градуси
 "mirror": false,
 "pieces":  [ {"v": [[0,0],[100,0],[100,60],[0,60]],
               "c": [null,null,null,null]} ],   // c[i] — контрольна точка Без'є ребра i→i+1
 "blocked": [],                      // заборонені зони (той самий формат)
 "reference": {"name":"Еталон","length":400,"polys":[ ... ]}   // необов'язково
}
